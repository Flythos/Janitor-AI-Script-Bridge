Janitor AI Script Bridge
Runs Janitor AI bot scripts in SillyTavern: JS scripts execute before every generation (send, swipe, regenerate, group drafts) and their output is injected into the prompt for that turn only. Lorebook JSON is converted 1:1 into a native World Info book linked to the selected character.
Script library
Script stack —
Runs top to bottom; later scripts see what earlier scripts added. Drag to reorder.
Imported Janitor lorebooks
Imported lorebook JSON becomes a regular World Info book linked to the character at import time. Min-Messages and Group-Selection rules are enforced by this plugin per generation.
